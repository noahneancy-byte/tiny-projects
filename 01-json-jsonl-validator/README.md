# Dataset Check

一个无需联网的 Chrome 扩展，用来检查 JSON / JSONL 数据集的格式和常见质量问题。

## 功能

- 自动识别 JSON 与 JSONL
- 精确提示 JSONL 错误行
- 检查缺失字段、空值和字段类型不一致
- 检查重复记录和常见标识字段的重复值
- 展示记录数、字段数和字段结构
- 导出 JSON 格式的检查报告
- 文件仅在浏览器本地处理，无需任何网站权限

## 安装

1. 下载并解压本项目。
2. 在 Chrome 地址栏打开 `chrome://extensions/`。
3. 打开右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本项目文件夹 `01-json-jsonl-validator`。

安装后，将 Dataset Check 固定到浏览器工具栏即可使用。

## 支持格式

- `.json`：顶层数组或单个对象
- `.jsonl`：每行一个 JSON 对象
- 单个文件最大 10 MB

## 隐私

扩展不请求任何网站权限，不发送或保存用户数据。
